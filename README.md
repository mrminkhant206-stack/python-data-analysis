
# CSV Data Validator

A beginner Python project for validating CSV sales data.

## Features

- Read CSV files using Pandas
- Check required columns
- Detect invalid quantities and prices
- Validate revenue calculations
- Export validation errors to CSV
- Summarize sales data

## Tools

- Python
- Pandas
- Google Colab
- GitHub

## Files

- `csv_data_validator.ipynb` - Python notebook
- `sales_data.csv` - Sample sales data

## How to Run

1. Open the notebook in Google Colab.
2. Run each code cell in order.
3. Review the validation results.
4. Download the error report.

## Learning Goals

Practice Python, data validation,
error reporting, and GitHub version control.
